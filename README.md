# SVN Save Editor — Hypper Remastered

Редактор сохранений для **Hypper Remastered** (модификация Hypper Sandbox).
Работает с файлами сохранений карт в формате `.svn` (JSON). Позволяет быстро
сваривать пропы, скрывать/показывать их пачками и сохранять результат прямо
в папку игры.

---

## Возможности

- 📂 Открытие `.svn`, `.json`, `.txt` файлов (UTF‑8 и CP1251).
- 📝 Просмотр и ручное редактирование JSON в текстовом редакторе.
- 🗂 Боковая панель с сохранениями игры (сортировка по дате изменения).
- 💾 Сохранение прямо в `...\Hypper Sandbox\Saves\` с расширением `.svn`.
- 🛠 Расширяемая система инструментов (каждый — отдельный класс).

### Инструменты

| Иконка | Инструмент | Что делает |
|--------|-----------|------------|
| 🔗 | **Сварка** | Последовательно соединяет пропы по `weldTargetSaveIds` в диапазоне `[От, До]` |
| 🧹 | **Очистка сварки** | Очищает `weldTargetSaveIds` у пропов в диапазоне |
| 👁 | **Видимость пропов** | Массово делает пропы видимыми / невидимыми (`invisible`) |

## Установка

1. Установите **Python 3.10+** (используется `str | None` и `list[str]`).
2. Скачайте скрипт, например `svn_editor.py`.
3. Запуск:

   ```bash
   python svn_editor.py
   ```

---

## Быстрый старт

1. Запустите редактор.
2. Нажмите **«Выбрать файл…»** и откройте вашу карту
   (`*.svn`, `*.json` или `*.txt` с JSON внутри).
3. В правой панели выберите инструмент.
4. Заполните поля и нажмите **«▶ Применить»**.
5. Нажмите **«💾 Сохранить (в Saves)»** — файл попадёт в папку сохранений игры
   с расширением `.svn`.

Слева список всех сохранений в папке игры — двойной клик открывает файл.
Кнопка **🔄 Обновить** перечитывает список (например, после сохранения из самой игры).

## Формат `.svn`

Файл `.svn` в Hypper Remastered — это обычный JSON без обёртки:

```json
{
  "map": "FlatGrass",
  "props": [
    {
      "name": "Monitor",
      "uniqueId": 1789.30859,
      "saveId": 1,
      "weldTargetSaveIds": [],
      "wireTargetSaveIds": [],
      "invisible": false,
      ...
    }
  ],
  "saveVersion": 1
}
```

Ключевые поля для инструментов:

- **`saveId`** — уникальный целочисленный идентификатор пропа в файле.
  По нему адресуются все операции.
- **`weldTargetSaveIds`** — список `saveId`, с которыми текущий проп **сварен**.
- **`wireTargetSaveIds`** — список `saveId` для **логических связей** (LogicEvent,
  LogicAction, LogicCompare и т.д.). Не путать со сваркой!
- **`invisible`** — `true`/`false`, скрыт ли проп.
- **`uniqueId`** — `float`, уникальный идентификатор объекта. Редактор его
  **не трогает**.

## Как добавить свой инструмент

Инструменты — это классы-наследники `BaseTool`. Достаточно определить `icon`,
`title`, `build_ui(parent)` и `apply()`, затем зарегистрировать класс в списке
`FileEditorApp.TOOL_CLASSES`.

```python
class RenameTool(BaseTool):
    icon = "✏️"
    title = "Переименовать"

    def build_ui(self, parent):
        self.id_var = tk.StringVar()
        ttk.Label(parent, text="saveId:").grid(row=0, column=0, sticky="w")
        ttk.Entry(parent, textvariable=self.id_var).grid(row=0, column=1, sticky="ew")

    def apply(self) -> str | None:
        try:
            sid = int(self.id_var.get())
        except ValueError:
            messagebox.showerror("Ошибка", "saveId — число.")
            return None
        prop = self.app._prop_by_saveid(sid)
        if prop is None:
            return f"Проп {sid} не найден."
        prop["name"] = "Renamed"
        return None
```

Регистрация:

```python
TOOL_CLASSES = [WeldTool, ClearWeldTool, VisibilityTool, RenameTool]
```

Кнопка с иконкой и названием появится автоматически, а форма инструмента
построится при его выборе.

Полезные методы контекста `self.app`:

- `_prop_by_saveid(sid)` → `dict` пропа или `None`.
- `_get_props()` → список всех пропов.
- `json_data` → весь JSON как Python‑объект (изменения сразу попадут в файл при сохранении).

## Ограничения и предостережения

- **Резервные копии не делаются автоматически.** Перед массовыми операциями
  копируйте `.svn` вручную — в диалоге сохранения есть опция «сохранить с меткой
  времени», если файл уже существует.
- При ручном редактировании JSON ошибка парсинга покажется диалогом, и
  сохранение/применение инструмента не произойдёт, пока ошибка не исправлена.
- Значения `uniqueId` — не используются в игре, это рудимент из немодифицированной версии Hypper Sandbox.
